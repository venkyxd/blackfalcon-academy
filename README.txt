BLACKFALCON QUESTION BANK - INSTALL STEPS
1. On github.com create a new PUBLIC repository (for example: bf-qbank).
2. Unzip this file, then in the repository choose Add file > Upload files and upload ALL files inside (index.html, manifest.webmanifest, sw.js, both icons). Commit.
3. Repository Settings > Pages > Source: Deploy from a branch > main, folder / (root) > Save. Wait about a minute.
4. Your app address will be https://YOUR-USERNAME.github.io/bf-qbank/
5. On Android, open that address in Chrome, tap the menu (three dots) > Install app. It appears in your app drawer and works offline.
6. For an APK file: open pwabuilder.com, paste the address, choose Package for Android, download, and install it (allow installs from unknown sources).
To update later: replace index.html in the repository with the new one.
